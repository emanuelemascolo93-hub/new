# FireTV IPTV

Player IPTV per Fire TV Stick (1ª generazione, Fire OS 5 / Android 5.1) con lista M3U e VPN WireGuard integrata.

Build automatica via GitHub Actions: l'APK firmato è scaricabile dagli artifact del workflow "Build APK".

Installazione: `adb connect <IP_STICK>` poi `adb install -r FireTV-IPTV.apk`.
